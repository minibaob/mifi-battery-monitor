# 03 · 独立低电量监控脚本

设备不会主动通知，所以需要有人去"问"。这个脚本就是一个常驻的轮询器，适合跑在任何一台常开的机器上（旧手机 Termux、树莓派、路由器、NAS）。

纯标准库实现（除了读串口的工具），不依赖任何第三方包。

## 1. 架构

```
poller.py   后台线程，每 60 秒 GET 一次接口 → 产出 Snapshot
notify.py   状态机 + PushPlus 推送
ui.py       悬浮窗（可选，tkinter）
config.py   配置读写（%APPDATA%\MifiMonitor\config.json）
logger.py   按天轮转日志
main.py     装配 + 单实例锁 + 开机自启
```

关掉界面也可以只跑 `poller + notify`，做成 headless。

## 2. 状态机（这是整个东西的核心）

```
充电中 / 已充满        → 一律复位为"正常"，不提醒
电量 > 20%            → 正常（绿）
11% ≤ 电量 ≤ 20%      → 低电量（黄），等级上升时推一次
电量 ≤ 10%            → 紧急（红），等级上升时推一次
15% 直接掉到 8%        → 只发紧急，不补发普通
同一等级重复触发        → 30 分钟内不再推（冷却）
采样失败              → 状态冻结，不推、不改判断
```

关键设计：**只在"等级上升"时推送**，而不是"每次满足条件就推"。否则电量在 20% 上下抖动会把你烦死。

```python
if target < self.level:      # 等级下降，静默复位
    self.level = target
    return None
if target == self.level:     # 同级，看冷却
    if now - self.last_sent[target] < cooldown:
        return None
```

## 3. 用法

```bash
# 只看数据
python scripts/battery_monitor.py --once

# 常驻，低电量 20% / 紧急 10%
python scripts/battery_monitor.py --threshold 20 --critical 10

# 带推送 + 落 CSV
python scripts/battery_monitor.py \
  --webhook "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx" \
  --csv battery.csv

# iOS 通知
python scripts/battery_monitor.py --bark "https://api.day.app/你的KEY"
```

| 参数 | 说明 |
|---|---|
| `--host` | 设备地址，默认 `192.168.1.1` |
| `--interval` | 轮询间隔秒，默认 60 |
| `--threshold` | 低电量阈值，默认 20 |
| `--critical` | 紧急阈值，默认 10 |
| `--cooldown` | 同级冷却秒，默认 1800 |
| `--webhook` | 推送 URL，POST JSON `{"text": ...}`（企业微信/钉钉/飞书机器人通用） |
| `--bark` | Bark 推送地址 |
| `--csv` | 记录到 CSV（时间、电量、充电状态、信号…） |
| `--once` | 只采一次就退出 |

**Token 一律不写进代码**，从命令行或配置文件读。

## 4. 状态机断言清单

这套逻辑改动时容易悄悄退化，建议照下面逐条验证（不需要联网，构造假的 Snapshot 就能测）：

| # | 场景 | 期望 |
|---|---|---|
| 1 | 电量 `"100"` | 不提醒，等级 0 |
| 2 | 电量 `"18"` | 提醒一次，等级 1 |
| 3 | 紧接着 `"16"` | 冷却中，不提醒 |
| 4 | 再掉到 `"8"` | **只发紧急**，等级 2 |
| 5 | 重复 `"8"` | 不重复提醒 |
| 6 | 从正常直接 `"9"` | 只发紧急，不先发普通 |
| 7 | 紧急状态下充电 | 不提醒，等级复位 0 |
| 8 | 充满 | 不提醒 |
| 9 | 拔电后 `"19"` | 重新开始，发普通提醒 |
| 10 | 采样失败（离线） | 无提醒，等级冻结 |
| 11 | `battery_percent="abc"` | 判为无效，不当 0% |
| 12 | `"150"` | 判为无效 |
| 13 | `"0"` 且 `battery_connect="0"` | 判为无效 |
| 14 | 离线快照 | 电量沿用上次值，`updated` 不变 |

## 5. 开机自启（Windows）

```python
# autostart.py 写 HKCU\Software\Microsoft\Windows\CurrentVersion\Run
# 不需要管理员权限
autostart.enable()   # pythonw.exe "main.py"
autostart.disable()
```

Linux / Termux 用 systemd user unit 或 `crond`，思路一样。

## 6. 局限

- 只能跑在**另一台常开的设备**上。设备自己关机了，脚本也就断了——但这恰好也算一种"断电提醒"（微信会因为收不到心跳而发现异常，如果你额外加了心跳）。
- 没有电压，所以无法做"电池健康度"或"精确剩余时间"估算，只能按百分比。
